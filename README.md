# آواب | AWWAB

تطبيق إسلامي مبني باستخدام Flutter وDart.

## التشغيل
1. ثبّت Flutter وAndroid Studio.
2. من مجلد المشروع نفّذ:
   `flutter pub get`
3. شغّل التطبيق:
   `flutter run`

## الهوية
- واجهة سوداء وبيضاء.
- تصميم زجاجي بسيط.
- شريط تنقل سفلي.
- دعم العربية واتجاه RTL.

> هذه بداية هيكل المشروع. مواقيت الصلاة والأذان والقرآن الكامل تحتاج ربط مصادر موثوقة واختبارًا قبل الاعتماد عليها.
